# 📰 India News - News Web App

A responsive and dynamic news website that fetches the latest articles using the  [NewsAPI](https://gnews.io/) based on user input or selected categories. Built with HTML, CSS, and JavaScript.

## 🌟 Features

- 🔍 Search functionality to fetch news on any topic
- 📑 Category-based quick filters (IPL, Finance, Politics, etc.)
- 🖼️ Dynamic news cards with images, source, and timestamp
- 🧭 Responsive design for both desktop and mobile views
- ⚡ Loads trending news by default on page load

## 🚀 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- [NewsAPI](https://gnews.io/)
